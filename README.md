A small Python entry that writes a single two-part, unsent micro-confession. The note is addressed to a sister and anchored in a specific family loss: the blue sweater she asked to bring to the hospital.

## Run

Requires Python 3. The program creates `/output` if needed and writes UTF-8 text to `/output/entry.txt`:

```sh
python3 main.py
```
